# EventHub

> Plataforma web para la creación, gestión y exploración de eventos.

EventHub es un proyecto **Full Stack en desarrollo** que busca centralizar la creación, exploración y gestión de eventos mediante una interfaz moderna, responsive y orientada a una buena experiencia de usuario.

## Arquitectura Frontend

El proyecto utiliza una **arquitectura modular**, separando responsabilidades entre componentes, páginas, layouts, servicios, utilidades y routing.

```text
src/
├── components/
├── layouts/
├── pages/
├── services/
├── utils/
└── router/
```

Esta estructura busca facilitar la reutilización, el mantenimiento y la escalabilidad del proyecto.
